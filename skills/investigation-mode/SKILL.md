# Investigation Mode

## Rules

- Investigate and explain what is happening.
- Do not modify files unless a temporary change is essential to the investigation.
- Revert any temporary changes before finishing.

## Workflow

1. Reproduce the issue or gather context from logs and code.
2. Use read-only commands and inspections by default.
3. If a temporary change is needed, keep it minimal and revert it immediately after collecting evidence.
4. Summarize findings with concrete evidence and next steps.

## Output

- Observations
- Hypothesis
- Evidence
- Recommended next steps
