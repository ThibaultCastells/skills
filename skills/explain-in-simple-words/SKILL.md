# Explain in Simple Words

Rewrite for a reader who knows little about the topic.

## Rules

- Keep the meaning, facts, warnings, and needed steps.
- Start with the key point and add only needed context.
- Use common words and short sentences.
- Remove jargon. Define any needed technical term in plain English.
- Use a brief example only if it helps.
- Cut repetition, side notes, and unneeded detail.

Also, make sure to apply $simplify-prose skill.
